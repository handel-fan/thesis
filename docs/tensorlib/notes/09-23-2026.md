# MLIR Thesis Ideas

<!-- markdownlint-disable MD013 -->

| Idea | Product version | Research / novel version |
| --- | --- | --- |
| **1. Automatic memory-layout selection** | Add AoS→SoA lowering to MLIR | Develop an analysis that decides when AoS, SoA, or hybrid layouts should be used, and automatically inserts/reorders layout transformations |
| **2. Layout transformations as first-class IR** | Implement transpose/layout ops | Represent layout constraints abstractly and delay choosing a physical layout until enough information about consumers/hardware is known |
| **3. Automatic transform selection** | Write tiling/fusion passes | Infer an MLIR Transform-dialect schedule from properties of the program instead of requiring a human-written schedule |
| **4. Correctness checking across lowering** | Lower dialect A → Linalg | Automatically verify that a lowering preserves the meaning of the source operation |
| **5. Numerical-error-aware lowering** | Lower tensor math into MLIR | Choose rewrites/precision based on an explicit bound on numerical error instead of treating mathematically equivalent rewrites as interchangeable |
| **6. Mixed precision inferred by compiler** | Support FP16/FP32/FP64 | Automatically assign precision to intermediate values while satisfying an error constraint and minimizing estimated cost |
| **7. Shape/layout-aware optimization** | Implement broadcasting | Use static shape/stride/broadcast information to select fundamentally different implementations of the same operation |
| **8. Cross-dialect optimization** | Implement A→B→C | Show that an optimization cannot be expressed effectively at either A or C alone, and introduce an intermediate representation/analysis that preserves exactly the information needed for it |
| **9. Domain-specific fusion discovery** | Fuse a couple operations | Automatically discover profitable fusion regions based on domain semantics rather than syntactic adjacency |
| **10. Extensible lowering rules** | Hard-code frontend→MLIR conversions | Design a mechanism by which libraries declare semantics/lowering properties that generic compiler machinery can consume |
